# Server beta 118

A coordinated answer now identifies the model that wrote its final response.
If the coordinator answers after reading a delegated result, its model appears
in the footer. When a member replies directly, that member retains authorship.
The answer also keeps separate paragraphs when the model writes again after a
tool call. Text within each streamed message keeps its original spacing.

The server receives these changes from the versioned Core dependency. See the
[channel guide](../site/guide/channel-history-media.md).
