# Python product 1.1.9 beta39

A fresh installation now starts with its own workspace tools. The server
resolved `filesystem`, `editor` and `shell` on the agent host only when the
catalog already had their rows, but startup created rows only for the opt-in
computer tools, so a new database had no tools on the agent's own computer
while migrated installations kept the rows earlier versions had seeded.
Startup now adds a row for every selected `server_host_tools` entry that has
none. Existing rows, including disabled and historical ones, are unchanged,
and `server_host_tools: false` or an explicit tool list still decide what is
exposed. Core beta83 is unchanged; identity, vault, automation and Custom View
data remain in place.
