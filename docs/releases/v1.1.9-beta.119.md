# Server beta 119

Agents using file or document storage now skip loading the project-task broker
at startup when `project_tasks` is unset. Their authenticated project catalog
returns empty lists for projects and tasks. Enabling `project_tasks` loads the
broker and registers the computer viewer and task-surface routes.
[Project task configuration](../site/guide/project-tasks.md).

This release includes Core beta 182. Text sessions load the optional cloud
speech backend only when a speech request needs it. Streaming synthesis
forwards audio chunks as they arrive. Structured tool decisions use the action
names in the model response schema.

If a local stdio MCP source times out during startup or reconnection, the
runtime gives its background handshakes more time. Concurrent callers share
the recovery attempt and can stop waiting independently. Recovered tools keep
their existing access rules.
