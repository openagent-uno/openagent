# Server beta 119

Agents using file or document storage now skip loading the project-task broker
at startup when `project_tasks` is unset. Their authenticated project catalog
returns empty lists for projects and tasks. Enabling `project_tasks` loads the
broker and registers the computer viewer and task-surface routes.
[Project task configuration](../site/guide/project-tasks.md).

This release includes Core beta 182. Opening a text stream leaves the optional
LiteLLM speech SDK unloaded. The first transcription or synthesis request that
uses this adapter loads it on a worker thread. For streaming synthesis, the
adapter forwards each nonempty audio chunk as the SDK yields it.
[Audio host contract](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.182/docs/audio-host-contract.md).

Models using the JSON Schema tool protocol select a function by its advertised
name in `next.action`. A final reply in `next.answer` can contain literal JSON.
[Structured tool decisions](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.182/docs/capability-discovery.md#compatible-endpoints-with-json-schema).

If a local stdio MCP source times out during startup or reconnection, the
runtime gives its background handshakes more time. Concurrent callers share
the recovery attempt and can stop waiting independently. Recovered tools keep
their existing access rules.
