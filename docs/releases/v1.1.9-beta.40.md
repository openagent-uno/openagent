# Python product 1.1.9 beta40

Adopts Core beta84 and OpenAgent Tools beta7.

A turn that fails or is cancelled after running tools no longer disappears
from the model's working history: the executed tool calls and their results
are replayed, closed by a note that the turn ended without a final answer, so
the next turn neither forgets nor repeats those side effects.

Server-host shells refuse a `timeout` below one second with an error that
names the unit (milliseconds) instead of terminating the command after a few
milliseconds; models had been passing seconds. On macOS a shell started from
a GUI-launched host resolves the user's login-shell `PATH`.

Identity, vault, automation and Custom View data remain in place.
