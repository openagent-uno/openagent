# OpenAgent App v1.1.0-beta.37

Typed messages and steering appear immediately. The transcript shows formatted
tables, lists, links, images, code and color samples. Active tools show a
moving highlight. The phone navigation drawer contains the agent switcher,
and the footer shows the connection state.

Use Server beta 24 for live child links, private text forks and the independent
agent desktop viewer. The viewer supports both read-only access and control.
