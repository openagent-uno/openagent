# OpenAgent App v1.1.0-beta.37

Messages appear immediately when sent. Session transcripts support richer
Markdown and show per-message copy, fork and time actions. Delegated child
sessions can open while the child is running. On phones the agent switcher
appears inside the navigation drawer, and the sidebar shows connection status.

Open the execution host's desktop from Devices or the session sidebar.
The host viewer requires [Server beta 24](v1.1.9-beta.24.md) and desktop
access for the current account. The session context panel uses a single border.

The [native qualification receipt](../qualification/app37-native-release-2026-11-10.json)
records the six packaged targets and verified public beta feeds.
