# OpenAgent 1.1.0 beta64

Explicit Telegram owner vault access now recognizes the stable typed channel session used by current private messages. The policy recomputes the exact bot, sender, direct conversation, binding and thread identity from the existing operator configuration. The authenticated bridge principal, private audience and both owner and channel allowlists remain required; groups, other accounts, other senders and deferred turns remain excluded.

The shared session identity helper preserves the existing hash byte for byte. Existing sessions, note ownership, vault contents and operator grants remain intact, and legacy private sessions remain supported. Regression tests cover vault and vault-gate discovery, native memory read/publish authorization, mismatched identities, revocation and environment token configuration. Core/SQLite beta32 and channel bridges beta13 remain the qualified dependencies. Native desktop bundles are unchanged.
