# Server 1.1.9 beta80

Pins Core 1.1.0b127 (which includes Core beta124–126, durable operations for
embedding hosts; the server does not use them yet).

- **Image generation says why the provider refused.** The `media-gen` tool
  result now quotes the provider's own message and error type, with the HTTP
  status, instead of a bare "429 Too Many Requests". A subscription service
  whose accounts all need a new sign-in is reported as that, not as an
  exhausted quota.
- **A turn answered by a backup model is labelled with the backup.** When the
  session's model fails and a backup answers, history and the live view of the
  session show the backup, not the model that failed. Turns recorded before
  this release keep their stored label.
