# OpenAgent beta57: admitted channel acknowledgements and media preflight

Framework beta57 adopts official channel bridges beta9. It preserves Core 28
and the eight other product distributions from their public beta56 manifest:
CLI/MCP/identity/dashboards/client transport/support beta56, HostTools beta6 and
product-config 18. Only the framework wheel is rebuilt; source and byte equality
of retained components are checked independently, without inherited acceptance.

Slack/Discord quiet acknowledgement precedes history downloads and speech.
Provider membership is checked at bounded transfer boundaries, with fresh host
authorization on every chunk. Requested history failure is explicit; original
audio survives recoverable transcription failure only while current authority
remains valid. Closed diagnostics contain no content or secrets.

Installed and public qualification are separate release receipts. Deterministic
fixtures do not establish real Slack/Discord, model or business-task acceptance.
No native App, frozen server, updater or paid CI is part of this Python release.
