# Server 1.1.9 beta73

Pins Core 1.1.0b114.

- A connected device can be lent to one of its owner's automations. From the
  desktop app's Loops panel, the person who approved a loop can let it use
  this computer while it is connected ("Use this computer"), and withdraw
  that at any time. Every discovery and call rechecks the loop's active
  grant, its unchanged definition and the consent. Without a consent,
  automations still see no device.
