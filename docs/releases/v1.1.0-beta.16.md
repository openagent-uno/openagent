# OpenAgent v1.1.0-beta.16 Telegram voice repair

The reusable stream fix is in [OpenAgent Core v1.1.0-beta.8](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.8). A turn marked `source="stt"` retains its original audio in the journal and artifact store while routing only the transcript and any non-audio attachments to the chat model. The standalone server also transcribes Telegram audio-file messages. Beta 16 pins PyAV below 19 for the local `faster-whisper` 1.2.1 path. Beta 15 was superseded before deployment because it did not include that dependency constraint.

The [beta 16 product release](https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.16) was built from clean commit `7aca6959ee7931e90017027ecde1984ae3924c5e`. Its nine wheels and manifest have manifest SHA-256 `c05b6bf343357b0c07f1a1a89bebfcd41e560f2631af0008f195ca402eb09221`. The public installer's `--check` verified all 38 published Core, product and Tools wheel hashes. A fresh Python 3.12 install passed `pip check`, `openagent selfcheck`, and the focused CLI packaging tests (18 passed). Core's public suite passed 133 tests and 23 subtests. The [documentation deployment](https://github.com/openagent-uno/openagent/actions/runs/37108890908) succeeded on the beta 16 commit.
