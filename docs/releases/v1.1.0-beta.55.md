# OpenAgent beta55: main-chat replies and explicit threads

The standalone server pins official channel bridges beta6. Top-level Slack
messages receive replies in the main chat. Existing Slack threads stay in
that exact thread, for text and files; unrelated destinations are denied.
Discord retains its explicit channel or thread destination. Session identity,
participant attribution and history remain unchanged. Beta5 upload byte,
authorization and file-identity guards are preserved.

One framework wheel is rebuilt. Eight product wheels retain their original
public bytes and provenance, including CLI beta52 and Host Tools beta6.
Core stays official beta24. Normal installed tests use deterministic provider
and model boundaries, including real local HTTP, not live provider accounts.
No Electron App or frozen server binary is rebuilt; existing frozen installs
need a separately rebuilt native server. The normal Python installer acquires
the published wheels; existing auto-update feeds are not qualified here.

Public asset hashes and fresh installed qualification are published as
separate immutable release receipts after publication. Previous tags and assets
remain unchanged. No paid Actions run.

Official release: [v1.1.0-beta.55](https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.55).
All 15 original public assets and the separate post-publication receipt were
fully downloaded and SHA256-verified. A fresh normal installation from these
public wheels passed 100 tests and 84 subcases with zero skips and pip check.
See the [public qualification](../qualification/product-beta55-2026-10-22.json).
