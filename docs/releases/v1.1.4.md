# OpenAgent 1.1.4 candidate

Cold Python subprocess imports could consume the management MCP handshake
deadline before the gateway became ready. A real VPS startup reproduced the
budget module failure under severe host CPU contention. The standalone product
now explicitly selects Core41's instance-owned management adapters for models,
budgets and skill data. They retain the public SDK tool schemas and protocol
results, with separate runtime and absolute database bindings. Other capability
transports and independently packaged module defaults remain unchanged.

Failed or cancelled server context entry now closes partially initialized
services and the host-owned Agent database before propagating the original
startup error. A later cleanup failure cannot hide that error.

Voice prefetch imports optional libraries on a worker so a cold import cannot
block gateway requests. Runtime context follows the import work; model-loading
coroutines retain their original event loop and cancellation stops subsequent
warmup steps.

This candidate uses product-config beta20 with Core41, Tools6 and signed Host
B7. It does not replace any previously published wheel or release asset.
Installed-wheel, startup rollback, public installer and production acceptance
are recorded separately after their checks complete.
