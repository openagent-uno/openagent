# Python product 1.1.9 beta52

Core 94: session retention no longer deletes interactive conversations.

- Pins Core 1.1.0b94 (core, gateway, sdk, storage-sqlite).

- The run-log step of session retention deleted any legacy session row with
  `session_type='agent'` idle for a day or larger than 500 KB. On 1.1 that
  includes conversations with the user, which were then marked deleted in the app
  and later lost their messages. Only `scheduler:*` and `automation:*` run-logs
  are now affected; conversations are bounded by `retention.days` alone.
- Run-logs of scheduled runs are kept for `retention.scheduler_days` (default 7)
  and an oversized one is trimmed to its newest run instead of being deleted.
- Also includes Core's default-router invariant and clearer errors for empty
  accounts and oversized requests.
- Host Tools stays 1.0.0b18; capability-host stays 1.0.0b4; product-config stays
  1.1.0b25.
