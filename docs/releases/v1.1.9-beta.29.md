# Server 1.1.9 beta 29

Adopts Core beta 78 for destination-aware source discovery and session-linked
tool images. Connected-computer screenshots can supply a marker the model can
explicitly attach to its final answer, using the admitted bytes instead of
interpreting a device path on the server.

The server publisher verifies the current run, session and recipient authority
before and after upload. A filesystem reader error becomes an unavailable
attachment rather than aborting a valid response. Existing reader roots and
revocation checks remain enforced.

The seven server/CLI product wheels retain a coordinated version. Host Tools, Device Tools,
connectors, channels and product configuration retain their independent pinned
versions. No desktop binary update is required for this server capability.
