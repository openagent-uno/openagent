# Python product 1.1.9 beta55

Core 97: agents see and find their own tools; product prompt corrected.

- Pins Core 1.1.0b97 (core, gateway, sdk, storage-sqlite).
  - Every run's system prompt ends with a `<capabilities>` map of the sources
    the turn can use: what each is for, the computer or account it acts on,
    its tool count and, for small sources, its tool names.
  - Discovery returns source descriptions, resolves older source names
    (`scheduler`, `workflow-manager`, `memory-search`…), stems search words,
    and suggests sources when nothing matches. External MCP servers' own
    `instructions` describe them when the framework has none.
- openagent-product-config 1.1.0b26: the default host prompt no longer claims
  tool calls are pre-approved by one backend, no longer creates schedules
  without asking, no longer makes delegation a hard rule (also sent to
  workers), uses current source names, and puts the user's and the agent's own
  instructions first. About half the size.
- Host Tools stays 1.0.0b18; capability-host stays 1.0.0b4.
