# Python product 1.1.9 beta45

Ships Host Tools beta17 and `openagent-capability-host` 1.0.0b4 (Core release
beta87) for the server's own computer tools and the CLI. When an agent issues
several mutating calls to the same computer in parallel, the later calls now
wait for the mutating lease and run in turn instead of failing with
`lease_held`; calls from a different principal are still refused at once. The
shared local broker reports its version and replaces an older broker left
running by a previous installation. Core stays at beta86. A server that installs
the native Host Tools bundle must use the beta17 bundle with this wheel.
