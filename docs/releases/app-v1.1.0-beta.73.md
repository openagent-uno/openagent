# App beta 73

Open **Projects** on a connected agent to choose an approved revision and start a task. Reopen the task after closing the client to see its status, final response and saved Git diff. On a host with the relevant permissions, the desktop client can reattach to the task computer's terminal and display its local preview.

The project workflow requires Server 1.1.9b106 or later and a configured project. The host operator selects eligible members, revisions and computer permissions. [Project tasks guide](../site/guide/project-tasks.md).
