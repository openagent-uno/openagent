# Server 1.1.9 beta67

Pins Core 1.1.0b110, tool-discovery 1.1.0b3 and openagent-modules(-full)
1.1.0b6; openagent-product-config 1.1.0b28 (pins openagent-modules-full
1.1.0b6).

- The system prompt explains computers and browsers (`core.computers`): the
  narrowest kind of tool on each target, the person's signed-in browser
  through screen control, checks after each change, no secrets or CAPTCHAs,
  and a look at every target before saying something cannot be done.
- A shell command on a connected device runs for the timeout it asked for
  (up to 600 s). Before, every device call ended at 120 s; a longer command
  became an indeterminate failure and the turn lost the device.
