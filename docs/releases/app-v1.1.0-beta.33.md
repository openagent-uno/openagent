# OpenAgent App v1.1.0-beta.33

The avatar rail switches saved agents in the same window. Desktop warms
saved logins with remembered credentials and reuses their authenticated
connections when ready. Those connections share one Iroh endpoint per
device and keep separate certificates.

The session details drawer opens alongside the header and keeps its
content width during the animation. Set a thumbnail under Agent Identity.
For server-managed profiles and bot synchronization, see
[Server beta 21](v1.1.9-beta.21.md).

The [native qualification receipt](../qualification/app33-native-release-2026-11-09.json)
records the six packaged targets and the verified update feeds.
