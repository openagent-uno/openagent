# Python product 1.1.9 beta17 candidate

This source candidate adopts the public Core53 cohort and the merged mapped-channel
history recovery fix. The seven coupled product distributions use `1.1.9b17`;
`openagent-product-config` is independently versioned as `1.1.0b22` and selects
full modules `1.1.0b4` (including Sessions `1.1.0b3`). Updating only Core/SQLite
would leave an incompatible exact full-profile/configuration pin behind.

The normal Python release workflow therefore builds eight wheels, retaining the
configuration package's own version. Its qualifier checks each candidate digest
and installs every declared checksum-pinned external Core/module/Tools wheel,
not only the four coupled Core packages. Dependency consistency, exact imports
and normal product tests remain required. Source locks follow the verified
public artifact hashes; no source overlay or copied engine is installed.

## Conversation continuity

Mapped channel Sessions list/search/read/publication keep exact current-conversation,
descendant and fresh-audience checks. Unrelated chats, changed membership and
session administration remain denied. The explicit Telegram provider regression
recreates the bridge after a four-day proof-time gap and replies to the earlier
event; its conversation key remains unchanged and it does not become a forum thread.

Core's optional Sessions tools recover details missing from a lossy recap. A
separate real remote embedding check found the three expected synthetic Italian
conversations after aged timestamps and SQLite reopen. This does not turn on a
semantic model for installed agents, prove generative-model continuation quality,
or attribute any specific live Telegram report.

## Release and installation boundaries

This document describes a candidate until the exact product tag, public artifact
hashes and installed qualification receipt are recorded. Native App/Host Tools,
identity keys, existing user state and updater feeds are not changed by this Python
cohort. A newly pinned installer is bound only after the published product manifest
is known; preserve complete existing state before any selected installation upgrade.
No installed-agent upgrade or live Telegram delivery is claimed here.
