# OpenAgent beta58: current channel speech authorization

Framework beta58 pins official channel bridges beta10. Historical voice input
and speech output refresh the explicit audience proof immediately before each
host speech callback, and verify current membership and host authorization
again after it completes. Slow speech no longer leaves the next file using
an expired intake-time proof. Real revocation and audience changes still deny.

Only the framework wheel changes. Core 28 and the eight immutable product
components from the beta57 manifest remain unchanged, subject to exact source
and wheel equality checks. Component fixtures and normal installed/public
qualification do not establish real Slack/Discord or business-task acceptance.
No native App, frozen-server rebuild or paid CI belongs to this Python release.

The same public component permits an explicitly configured history window of
up to 200 messages, with finite same-channel/thread provider pagination. Its
default of 20 and all quoted-context, part, file-count and byte budgets remain
unchanged. Hosts must independently admit their configured range.
