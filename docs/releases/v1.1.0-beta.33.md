# OpenAgent v1.1.0-beta.33: authorized automation composition

Product beta 33 fixes two failures reproduced inside Mixout's real Marketing
Content Pipeline after beta 32 removed the premature 960-second cancellation.

First, an unattended scheduled task could discover and call the workflow tools,
but `run_workflow` required the owner's broad `automation.read` permission before
checking the target workflow's durable authorization. The task therefore could
not invoke an independently approved pre-publication gate. A delegated
automation may now enqueue another automation only when both exact revisions
still have active grants and their initiating principal and audience match. It
does not gain list, edit, approval, or general management access.

Second, Core's internal `search_all` federation aborted when any one domain was
unavailable or unauthorized, discarding usable results from every other domain.
Core beta 18 isolates each provider, reports unavailable domains explicitly,
and labels this surface as OpenAgent-internal search. Its mandatory prompt and
tool description now direct public-Internet queries to the independent
`web-search` MCP instead. A live direct call to that MCP returned three real
results during incident qualification.

Regression coverage verifies successful same-principal task-to-workflow
composition, denial across principal boundaries, and partial federated-search
results when other domains fail. Product beta 33 is paired with Core beta 18
and Tools beta 4. The signed desktop App remains beta 15 because these repairs
are server-side.
