# Product beta92 — provider-scoped native subscription custody

The Python product adopts public Core beta143. Hosts can share only a selected
subscription provider's canonical credential and admission directory. Existing
flat stores and account/model references retain their behavior. Catalog
localization remains an explicit drained-host operation, with source/store
verification and no history or model reconstruction. Core beta141 stream
cancellation and beta142 exact-account quota telemetry remain included.

Publication, host data migration and authenticated live acceptance are separate
qualification boundaries; this release does not alter App identities or consent.
