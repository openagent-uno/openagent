# OpenAgent v1.1.0-beta.37: durable completion for replacement task hooks

Product beta 37 retains Core beta 20's SQLite/scheduler/summarizer fixes and
beta 36's explicit automation deadlines and truthful timeout projections.

The final Performa scheduled acceptance exposed another adapter ordering bug.
At 18:19 UTC, auto-update correctly recorded `update.check`, version beta 36,
`updated=false`. Its successful hook intentionally bypasses the standard
prompt executor, but Product checked the still-running task projection before
Core's outer dispatcher could finalize it. Both Runtime and the task history
therefore reported a failure for a completed check. The same signature appears
throughout the preceding days' auto-update logs.

Product now tracks whether a hook delegated to the standard executor. A
successful replacement hook finalizes its occurrence through Core's normal
scheduler finish path before Runtime publication. Manual replacement firings
also receive a durable task row. Hook exceptions still fail, and a delegated
executor that fails or omits its finalize is never reclassified as success.
Identical admitted requests remain idempotent.
Failed update checks propagate their exception after logging, rather than
returning normally and being mistaken for a successful replacement hook.

Tests exercise the real authorized Runtime, atomic scheduled claim, hook chain,
task projection, manual dispatch and duplicate-request path. They cover both
replacement-hook failure and an unfinished delegated executor. No task prompts,
cron expressions, grants, identities or database schema change.

Performa beta 36 already passed a live authenticated realtime response under
13 concurrent metadata writes, reconnect and `Continua` continuity, and a real
PWA watchdog occurrence completed successfully with a null Runtime deadline.
The beta 37 follow-up additionally qualifies actual auto-update completion.

The signed desktop stays beta 15. Higgsfield authentication remains a separate
external-credential issue: initialization returns HTTP 401 without a configured
refresh credential. This release does not grant missing historical revisions
or invent replacement credentials.

The source Product gate passes 94 tests and 23 subtests; CLI passes 99 tests
with one skip. The original Core beta 20 gate remains 168 tests and 23 subtests.
