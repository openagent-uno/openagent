# OpenAgent App 1.1.0 beta 50

- Recent stays live: scheduled runs, workflow runs and event deliveries
  appear, update and disappear as they happen, instead of after a reconnect.
- The Loops section offers Run now only while a loop is active: pausing a
  loop withdraws its authority, and the server refused the run silently.

With OpenAgent server 1.1.9 beta60 (Core 1.1.0 beta102) a loop's answer
appears in an open conversation without reopening it, and loop firings no
longer add rows to Recent. The app keeps Host Tools beta18, the existing
application ID, local profiles and device consent.
