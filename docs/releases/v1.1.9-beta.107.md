# Server and CLI 1.1.9b107

This beta adopts Core 1.1.0b169 and Device Tools 1.0.0b20 in the
standalone Server and CLI dependency closure. Host Tools Python 1.0.0b20
composes the same Device Tools release, with Execution and Shell 1.0.0b5.

SQLite history is available while search repairs its derived index in
bounded background batches. The scheduler fences dispatch and terminal
transitions against concurrent writers. Interactive requests can recover
the result of an admitted run by its stable request identifier.

Authorized discovery can show a temporary MCP or connector outage.
Transient handshake and metadata failures can recover between turns.
The runtime keeps uncertain tool effects from being replayed automatically.
Supervised browser sessions wait for their verified profile, and browser
references remain bound to their originating controller and context.
