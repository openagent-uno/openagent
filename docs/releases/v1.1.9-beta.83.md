# Server beta 83 — live Claude catalog and legacy model identifiers

Uses Core beta 131 for the authenticated Claude catalog and versioned short
family aliases. Existing model references retain their IDs and generation;
the upstream request receives its full Claude identifier. New catalog entries
come from the account's provider response, with conservative input capabilities
for unknown families. App beta 61 remains independently versioned.

Includes [Server beta 82](v1.1.9-beta.82.md). This follow-up is the qualified
provider migration pilot candidate.
