# Server beta 83 — live Claude catalog and legacy model identifiers

Uses Core beta 131 for the authenticated Claude catalog and versioned short
family aliases. Existing model references retain their IDs and generation;
the upstream request receives its full Claude identifier. New catalog entries
come from the account's provider response, with conservative input capabilities
for unknown families. App beta 61 remains independently versioned.

Includes [Server beta 82](v1.1.9-beta.82.md). This follow-up is the qualified
provider migration pilot candidate.

Qualification: the immutable Python release passed the installed product suite
and host ownership checks on Linux, Windows and macOS. The public installer was
executed into fresh server and CLI roots. Native computer/browser bundles and
the connector runner were verified; the CLI profile passed dependency checks
without SQLAlchemy, LiteLLM or provider SDKs. No server/model starts during the
CLI installation. App beta 61 passed all six desktop package targets and the
canonical publication gate. Native mobile devices remain a separate qualification.

The installer selects exact independently versioned module artifacts from the
server's pinned cohorts. It requests Core subscriptions explicitly while the
server owns its module-profile version. An optional installer GitHub token is
sent only to the GitHub API, never to release asset hosts.
