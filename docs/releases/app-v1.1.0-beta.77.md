# App beta 77

If the gateway rejects a chat message, select **Retry** on its **Not sent**
row. The app reuses the original request ID, text and uploaded files. A second
click while the request is in progress keeps the same turn.

If the connection closes before the gateway confirms delivery, **Check
delivery** looks up the original request. A matching receipt clears the
notice. If the gateway cannot confirm the turn, the notice stays in the
transcript and you can check again.

You can switch conversations, reconnect or reload the same desktop window or
browser tab and return to an interrupted message. Each account only sees its
own messages. Dismissing the notice, signing out or losing access clears its
recovery data. Closing the window completely can discard it.
