# OpenAgent server and CLI 1.1.9 beta33

Retains beta32's confirmed Telegram/WhatsApp tool-message history and edited
channel turns, adopting Core beta81 with channel bridges beta23.

Standalone stream channels now observe each admitted child through public
Runtime events while it executes. The child's own tool operations update its
separate progress message. These observers neither execute work again nor
cancel a child on detach; lineage and read permissions remain authoritative.
The collaboration observer retains its own existing subscription.

An input immediately following stop/reset waits for the old collector's
cancelled terminal boundary. Core beta81 also guarantees that boundary when
the cancelled runner never entered its cleanup block. A fresh input therefore
gets its own provider response instead of editing the stopped reply.

Focused source regressions exercise two live child operations, observation
detach/replay without repeated execution, and stop followed by a new collector.
Full installed-cohort, App and native host checks remain publication gates.
Real provider acceptance is limited to Telegram.
