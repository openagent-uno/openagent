# OpenAgent SDK 1.1.5

The server prepares startup invitation tickets through its already connected runtime database. Coordinator startup no longer opens another database connection or repeats schema initialization after the gateway has started. Invitation reuse, expiry, address hints and identity remain unchanged.

Identity CLI helpers distinguish borrowed runtime connections from connections they own. Owned connections are closed when initialization fails or is cancelled, and borrowed connections stay owned by the running server.

Custom View mutations roll back their owned transaction when cancelled and preserve the original failure if rollback itself fails. A failed transaction start leaves a pre-existing caller transaction untouched.

This release retains public Core beta41, modules beta37, Tools beta6, Host Tools beta7, Device Tools beta8 and product config beta20. Qualification and deployment evidence are recorded separately; these notes do not assert successful publication or production acceptance.
