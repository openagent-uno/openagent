# Product beta91 — embedded quota telemetry

The standalone packages adopt Core beta142 while retaining beta90's correction
for Codex stream ownership and cancellation. Native Claude account reads can
now show the safe quota telemetry captured from real provider responses.
Trusted monitors use the public exact-account `refresh_usage` operation and
ordinary Core inference, without reading OAuth tokens or requiring a separate
custody listener. Missing or stale quota remains unknown.

The protocol, model and account identities and customer settings are unchanged.
Offline localization remains an explicit drained-host operation with reviewed
account/store bindings. Publication, storage migration and real-host acceptance
are separate qualification boundaries.
