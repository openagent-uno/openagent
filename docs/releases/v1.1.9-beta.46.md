# Python product 1.1.9 beta46

The review of an approved automation now reports which capability sources its
grant covers and which current sources it does not (`GET
/api/automations/{kind}/{id}/authorization` returns `capabilities: {granted,
grantable, missing}`). A grant still never widens by itself: a source added
after approval, such as a newly selected computer tool, reaches scheduled runs
only once the owner approves the automation again. Device capabilities leased by
a connected client stay excluded from automations.

The server and the CLI ship Host Tools beta18, whose shell gives commands the
login-shell `PATH` of the user on macOS hosts started from the GUI. Core stays at
beta86 and `openagent-capability-host` at 1.0.0b4. A server that installs the
native Host Tools bundle must use the beta18 bundle with this wheel.
