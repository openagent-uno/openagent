# OpenAgent App v1.1.0-beta.35

Open the agent's configured desktop from Devices. Session details load
device history and available controls independently. An agent owner can open
its desktop from scheduled run, event delivery and workflow details even
when the run's transcript is unavailable.

Custom dashboards can display interactive HTML, JavaScript, SVG, Canvas and
WebGL in the desktop app's isolated viewer. Dashboards can bundle their own
assets and use the view bridge to read authorized data or request named
actions. The existing declarative dashboard format remains available.

These features use [Server beta 23](v1.1.9-beta.23.md). The
[native qualification receipt](../qualification/app35-native-release-2026-11-10.json)
records the packaged targets and public beta feeds.
