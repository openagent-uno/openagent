# Channel bridges 0.1.0 beta 35

When an editable reply ends, the channel removes the temporary waiting
indicator and keeps the final text. A delegated agent with a reported
outcome keeps its own result. If the parent finishes before the channel
receives an authorized outcome for the child, the child message shows
“Outcome unavailable” and clears its provisional narration.
