# Server beta 116

Delegated agents in a private channel can use an explicitly selected model
or automatic model selection. Core carries the recipients of the turn into
model authorization. Each child keeps its granted tools and devices.

The gateway filters a restricted update for the current viewer and continues
sending authorized updates on the same connection. Parent and child sessions
keep separate replay state. A reconnect during delegation can recover the
parent's progress after a child has finished.

Telegram shows the outcome reported by each delegated agent. When the parent
finishes before the channel receives an authorized final update from the
child, the child's message clears its provisional text and shows “Outcome
unavailable”. The parent message clears its waiting indicator.
