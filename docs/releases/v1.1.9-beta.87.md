# Server beta87 — typed account policy and shared custody accounting

This cohort consumes public Core beta137. The provider contract advertises local
account-policy fields so clients can update linked text/image connections
together. Declared image fallback preserves existing account groups, budget
admission and exact routing. The optional custody host aggregates request metrics
and usage across pooled and named-account routes without duplicate token stores.

Public host CLI composition and deferred tool transcripts remain available.
Independent module, capability, connector and native-host versions are retained.
Installed-wheel qualification, publication and live host acceptance are separate
gates.
