# OpenAgent App v1.1.0-beta.34

The avatar rail switches saved agents. The scheduled run screen uses the
authorized transcript when available and can show a run's saved output on its
own. A run that exceeded its execution limit shows the timeout in the details.

Use Models & Providers for API credentials and subscriptions, including usage
progress, and Costs for budgets. Agent owners can manage operational visibility
and ownership under Agent Access.

See [Server beta 22](v1.1.9-beta.22.md) for the companion release and
[the native qualification receipt](../qualification/app34-native-release-2026-11-10.json)
for verified targets and update feeds.
