# OpenAgent App 1.1.0 beta 51

- Pin: the row menu in the sidebar offers Pin/Unpin for conversations and for
  scheduled, workflow and event runs. Pinned rows show at the top, above
  Recent. Pinning a run pins its routine, so the row always opens the newest
  run of a routine that starts a fresh session each time (a daily task).
  Pins are kept per account on this device.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
