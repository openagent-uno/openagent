# Server beta 117

A private channel conversation can delegate work after using a note. Each
child can use the exact revisions admitted to its parent. The server checks
the conversation, recipients and revisions when the child starts and when it
returns its answer. A parent can include multiple child replies in its final
message.

Opening a conversation with an earlier protected document also preserves
the signed viewer's authorization when submitting a new attachment through
the app, HTTP runtime or WebSocket. A saved reply can return the original
file to the same conversation.

When approving a reviewed automation, a client can choose which of its
currently available tool sources the automation may use. The server binds
that choice to the reviewed definition and checks the sources again at
approval. A recurring schedule that missed earlier occurrences resumes at
its next scheduled time.
