# Server 1.1.9b105

Redelivered WhatsApp text notifications resume the original admitted run. The server preserves message and attachment associations when a completed stream replays after a reconnect. Distinct notifications with the same text still create separate turns.

The server and CLI use Core 1.1.0b164. The document vault supports authorized natural-language recall and limits repeated model reads of the same verified note revision. Enable automatic recall for a single instance with `memory.auto_recall.enabled`. The server honors an explicit false value, including a quoted YAML value.
