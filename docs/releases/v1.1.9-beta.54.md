# Python product 1.1.9 beta54

Core 96: session goals.

- Pins Core 1.1.0b96 (core, gateway, sdk, storage-sqlite).

- `/goal <objective>` gives a conversation a goal the agent keeps working on,
  continuing the same session on its own until it writes
  `[goal: achieved] <outcome>`, hands back with `[goal: blocked] <reason>`, or
  spends its continuation budget (default 20). `/goal status | pause | resume |
  done | max <n> | clear` manage it from the app, the CLI and every channel.
- New REST endpoints `GET/PUT/PATCH/DELETE /api/sessions/{id}/goal` (view to
  read, admin and the collaboration guard to change); every change emits a
  `session` `updated` resource event.
- Host Tools stays 1.0.0b18; capability-host stays 1.0.0b4; product-config stays
  1.1.0b25.
