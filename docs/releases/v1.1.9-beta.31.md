# OpenAgent server and CLI 1.1.9 beta31

Uses Core beta80 and channel bridges beta23. Live channel text turns edit one
main response; each admitted sub-agent has its own edited progress message.
Telegram and WhatsApp tool deliveries are recorded in the verified recipient
conversation without a fake user turn, including sends from scheduled jobs.

Retains Core beta79's one-level default delegation, reset-resistant worker
fence and isolated model fallback refresh. The standalone default depth is
also one; users can still explicitly configure a different host policy.

Late child events are bound to their exact parent collector and cannot leak
into another turn. Cancelled runs are shown as stopped. History-recording
failures after accepted sends are distinguished from unsent messages.

Source and installed-package checks are separate from provider acceptance.
Live provider QA for this change is limited to Telegram. Desktop binaries
are unchanged; these behaviors are owned by server/Core/channel packages.


The beta30 source candidate was not published: its gates exposed missing
direct App icon dependencies, shared TypeScript module resolution, an obsolete
Reanimated type import, and an installed-wheel qualifier that could retain an
older artifact with the same package version. Beta31 declares the icon package,
resolves shared source types from the consumer's locked dependencies, uses the
public SharedValue type, and reinstalls the exact selected first-party bytes
before qualification. It does not remove those release checks.


Source candidate only: web export failed and publication was blocked.
The exact shared-source aliases are qualified in [beta32](v1.1.9-beta.32.md).
