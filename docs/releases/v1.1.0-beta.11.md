# OpenAgent v1.1.0-beta.11 release receipt

This candidate pins [Core beta 6](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.6).
It adds image model configuration in App, CLI and the server API, and returns
generated images as channel attachments when the agent includes the image
tool's send marker. The App and Telegram, Slack, Discord and WhatsApp bridges
use the existing typed attachment path. Session pinning and compaction now
invoke the public Core control surface.

The Python product wheels were built from commit
`f370c4b34d9f15b8046b20b83d8608f888cc3639` and published as the
[beta.11 prerelease](https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.11).
All 11 published assets match the local SHA-256 digests and sizes. The
isolated product/Core/Tools installation passed dependency checking, server
selfcheck, CLI version and the focused CLI suite (99 passed, one skipped).

This release contains no desktop installer. The last signed and notarized
macOS desktop build is beta.10. Provider-backed image generation requires a
configured compatible model and has not been validated with a billable
provider in this release. Standalone production instances remain on beta.8
until a separate cutover is verified.
