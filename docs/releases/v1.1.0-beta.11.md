# OpenAgent v1.1.0-beta.11 release receipt

This candidate pins [Core beta 6](https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.6).
It adds image model configuration in App, CLI and the server API, and returns
generated images as channel attachments when the agent includes the image
tool's send marker. The App and Telegram, Slack, Discord and WhatsApp bridges
use the existing typed attachment path. Session pinning and compaction now
invoke the public Core control surface.

Source, package and delivery verification will be recorded after the release
artifacts and deployed instances are checked. Provider-backed image generation
requires a configured compatible model and has not been validated with a
billable provider in this candidate.
