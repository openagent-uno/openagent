# Python product 1.1.9 beta57

Session loops.

- Pins Core 1.1.0b99: a scheduled task can run inside a conversation (every
  firing is a turn of that chat, admitted with the task's captured
  delegation); the agent can loop its current conversation
  (`create_scheduled_task(..., in_this_conversation=True)`); compatibility
  alias sources are hidden from the capability map and discovery.
- `POST /api/scheduled-tasks` accepts `session_id` (admin access to that
  conversation required); `GET /api/scheduled-tasks?session_id=` lists one
  conversation's loops.
- Automation approvals: `definition_digest` ignores `target_session_id` while
  it is unset, so the new column leaves every existing task's approval valid.
- product-config stays 1.1.0b26; Host Tools stays 1.0.0b18.
