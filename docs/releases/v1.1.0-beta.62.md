# OpenAgent 1.1.0 beta 62

This product selects the independently published Core31 family and retains channel bridges13. Core31 distinguishes canonical runtime tenant authority from an exact, source-verified compatibility projection in the same SQLite file, including a normally deleted legacy session with retained deletion evidence. Foreign canonical tenants, altered or unbacked projections, unrelated derived rows and unknown tenant-bearing tables remain rejected. The public guard does not rewrite tenant IDs, authors, grants or historical content and does not resurrect deleted sessions.

Seven Python product components are newly built: framework, identity, client transport, dashboards, support integration, CLI and MCP bridge. Product-config18 and official host-tools6 retain their immutable public wheels and original provenance. Exact Core31 wheel constraints and normal lockfiles carry the change through the standalone consumer graph; existing channel, peer-policy and platform security boundaries remain in place.

Normal fresh local and public installed qualification is required, including the tenant-domain regressions, canonical history, channel processing and authorization fixtures, installed-prefix and RECORD checks, and CLI entry points. Actual counts and anonymous full-asset hashes are recorded in the release qualification assets after execution. This pure Python release does not claim a rebuilt native App, frozen server, updater migration, live provider or model acceptance. No GitHub Actions is invoked.
