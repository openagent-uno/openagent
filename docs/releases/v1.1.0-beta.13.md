# OpenAgent v1.1.0-beta.13 image subscription integration

This release pins Core v1.1.0-beta.7 across the standalone server, CLI, App transport, identity, dashboard, support integration and MCP bridge. Core uses a model's `image_generation` capability and `image_model_id` alias to call a provider's image endpoint, including a Codex subscription proxy with a qualified chat catalog ID. The Claude subscription proxy currently exposes chat only; a Friday turn can use Claude for reasoning and a separately configured image provider for drawing.

The Core public suite passed 131 tests and 23 subtests. The product package and live Friday image checks are recorded below when the exact released artifacts have been exercised.
