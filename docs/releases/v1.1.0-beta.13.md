# OpenAgent v1.1.0-beta.13 image subscription integration

This release pins Core v1.1.0-beta.7 across the standalone server, CLI, App transport, identity, dashboard, support integration and MCP bridge. Core uses a model's `image_generation` capability and `image_model_id` alias to call a provider's image endpoint, including a Codex subscription proxy with a qualified chat catalog ID. The Claude subscription proxy currently exposes chat only; a Friday turn can use Claude for reasoning and a separately configured image provider for drawing.

The Core public suite passed 131 tests and 23 subtests. Nine product wheels were published with the beta 13 release. The standalone Friday instance on Bluehost was upgraded to these released wheels after a coherent SQLite backup (`/srv/friday/backups/pre-beta13-20261002-2100-retry`), package dependency check and `openagent selfcheck`. The systemd service remained active with Telegram and WhatsApp bridges connected; its API health returned version `1.1.0b13`.

The live App session `session-1790975643471` asked Friday to draw a green mug. The first turn used Claude Opus through `claude-sub-proxy` and received the provider's account rate limit. With the user's permission, a temporary `codex-test:gpt-5.6-sol` provider was connected to the Spicy Sparks Codex subscription proxy. Friday then called `media_gen_generate_image` and attached the resulting PNG in the App chat. The successful run is `e40a4a0c-7fd4-4b5b-8183-bd7bb7a2f0f6`; artifact `art_b58f3844ca884b9b8a59b13c193ae4c6` is `image/png`, 1,650,759 bytes, SHA-256 `e62ade516a9b13f1da4c37796272321d4559a277354ce7aa03039066d74dc68c`. The App visibly rendered the green mug with a download control. The session was returned to `/model auto`, then the temporary provider, key file and SSH proxy tunnel were removed.
