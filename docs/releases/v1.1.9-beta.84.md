# Server beta 84 — negotiated JSON transfer and shared subscription contracts

The server consumes the exact public Core beta 133 cohort and declares the
optional gateway as a direct dependency. Buffered successful JSON reads use
Core's negotiated off-thread gzip middleware. Existing identity clients,
authorization failures, streams, range and conditional responses keep their
protocol semantics. No database or provider metadata migration is part of this
release. Core's public host-owned subscription grant/OAuth contracts are
available to embedding hosts; native subscription cards keep exact routing.

Local qualification: 620 product tests and 90 subtests passed, one skipped,
in a newly resolved environment. A real coordinator/member/device Iroh test
also passed with compressed wire bytes, exact decompression, authenticated
reads, transport reuse, revoked access, regrant and coordinator outage. Core's
public installed release was qualified separately. The App remains independently
versioned; beta 63 compacts provider cards and pauses unfocused provider polling.

Large recovered transcript payloads compressed by 6.6–8.2 times without content
changes in a private snapshot measurement. This is payload reduction, not proof
of a threefold improvement in production session-opening time. Release, public
installer execution and live host acceptance are separate gates.
