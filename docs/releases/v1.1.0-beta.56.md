# OpenAgent beta56: quiet final replies and historical channel media

This Python product source consumes official Core beta27 and channel bridges
beta7. Slack/Discord history retains file/image/video/voice messages through
request-scoped readers and ordinary session-scoped artifact authorization.
The explicit history_media capability is enabled by NativeChannelTransport
after normal CAS ingestion. Historical audio uses the same configured speech
service as current voice input. Unavailable media is identified explicitly.

Quiet delivery acknowledges once and sends only the runtime's authoritative
final_answer; the full transcript stays unchanged. Optional host-controlled
acknowledgement_text permits a specific language without locale inference.
Live progress remains opt-in. The client transport preserves canonical final
parts and path-free media references through stream collectors and gateway
frames. Missing final metadata is reported explicitly, never guessed from prose.

Seven pure Python wheels (framework, client transport, identity, dashboards,
support, CLI and MCP) are rebuilt for the exact compatible Core dependency
closure. HostTools beta6 and product-config beta18 retain their original public
bytes/provenance. No desktop app, frozen server or updater feed is rebuilt.

History remains bounded to latest configured N (0–100), 64 KiB of metadata,
16 combined current/historical files, 64 MiB combined media and 32 MiB per
historical file. No all-day paging tool or implicit provider connector grant
is introduced. Legacy gateway input does not advertise historical media.

Installed/public qualification is a separate immutable release receipt.
Deterministic provider fixtures do not qualify real Slack or Discord delivery.
Prior versions/tags remain immutable and no paid CI is used.
