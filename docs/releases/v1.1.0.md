# OpenAgent 1.1.0

The public installer now derives the server, CLI and Core requirements from the
metadata of the exact checksum-verified wheels it downloaded. Previously the
beta69 installer downloaded beta69/Core34 but still requested beta68/Core33,
which could fail installation or select an older package from an index. The
same verified wheelhouse now selects every directly installed component.
Server installs retain the channel and Core engine/provider/module extras.

A regression runs the real installer download program against independent
server/CLI release fixtures, checks the resulting requirements and ensures
no separately maintained product-version literal selects the installation.
Shell syntax and actual public package installation are qualified separately.

Iroh password login also supports srptools 2.x without changing existing
3072-bit verifier records or the ASCII-hex proofs used by desktop and CLI
clients. The constructor and proof representation changes previously broke
fresh installations. Deterministic desktop protocol vectors, wrong-proof
rejection and actual two-account Iroh registration/login cover compatibility.

This stable server/CLI product retains official Core/SQLite beta35, channel bridges beta14,
Tools beta4 and connectors 0.1.12. Deployment to existing installations must
preserve identities and durable history, validate migration on backup copies,
and run authenticated live provider checks after credentials are available.
Native App binaries are not rebuilt by this pure Python product release.

## Qualification and deployment

The published stable release contains nine Python wheels, the verified installer,
a source archive and checksum receipts. All 15 public assets were downloaded
anonymously and verified in full. A fresh macOS ARM64/Python 3.13 install verified
40 upstream wheels, installed the connector runner, passed dependency checks and
selfcheck, and passed the real two-account Iroh/model/tool/replay fixture.
The installed product suite passed 394 tests and 101 subtests on macOS; Linux
passed 393 tests and 101 subtests. Installer regressions passed 28 tests and the
subscription proxy passed 70 tests. Existing SRP 1.x fixtures also passed.

Three existing standalone agents were deployed after backup restoration and
migration checks, preserving identities, histories and personas. Each passed
owner-authenticated Iroh health, model catalog and reconnect checks from a Mac.
DeepSeek was removed from the live catalog and fallbacks. The catalog now exposes
Opus, Sonnet and Haiku 5.5 through proxy 0.1.4. An unowned installation was linked
to its authorized real owner and its two enabled automations were approved
through the authenticated revision-review API. Four duplicate daily cost jobs
were disabled with their definitions and history retained; one complete 08:00
Europe/Rome schedule remains enabled.

Actual Claude inference still requires renewed subscription credentials: the
previous refresh tokens expired. The owner requested the official one-year token
flow. Linux's native Iroh runtime fixture hit deadlines under substantial VPS CPU
steal; the equivalent macOS fixture passed. Iroh 0.35 also emits UniFFI teardown
thread warnings in asyncio debug tests. Previously observed native SIGSEGVs have
no confirmed root cause, so this release does not claim that crash resolved;
faulthandler and service restart monitoring are enabled.

See [the qualification receipt](../qualification/product-stable-1.1.0-2026-10-26.json)
for exact scope and public asset hashes. Native App binaries were not rebuilt.
