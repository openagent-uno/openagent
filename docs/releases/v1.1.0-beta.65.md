# OpenAgent 1.1.0 beta65

Telegram and other gateway-backed channels now deliver canonical generated assets in live and legacy final-only modes as well as quiet mode. The wire contains artifact references rather than local paths; the adapter previously skipped those references outside quiet mode, producing text without the promised files.

All modes resolve canonical attachments through the existing authenticated artifact-content route, verify size and SHA-256, revalidate the current channel audience and retain attachment order. Supplied local paths and external URLs cannot replace a canonical reference. Quiet final-answer selection and live narration remain unchanged. Regression coverage exercises the real wire/collector, authenticated HTTP reader, all three modes, denied delivery, missing assets, integrity failures and temporary-file cleanup. Core/SQLite beta32, channel bridges beta13 and native desktop bundles are unchanged.
