# OpenAgent Server v1.1.9-beta.21

The agent owner can save a thumbnail alongside the name in Agent Identity.
The server sends the updated profile to authenticated clients and queues
profile updates for configured Discord, Telegram and Slack bots. The settings
screen shows the outcome for each channel. Slack requires app configuration
credentials. See [the channel guide](../site/guide/channels.md#bot-profile-synchronization).

The server uses Channel Bridges beta 22 and Product Config beta 23. The
[qualification receipt](../qualification/python-product-b21-2026-11-09.json)
records the installed product tests and the installer checks. Provider profile
updates were exercised with fixtures.
