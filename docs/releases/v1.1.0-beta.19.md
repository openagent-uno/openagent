# OpenAgent v1.1.0-beta.19: subscription proxy media discovery

Claude and Codex subscription proxies now advertise their actual input and
image-generation capabilities in `/v1/models`. Core beta 10 retains those
fields during OpenAI-compatible discovery, including for a configured custom
provider URL. The standalone server queries that catalog when adding a model
whose media metadata was not set explicitly and persists the advertised
`input_modalities`, `capabilities`, and image model alias. Explicit model
settings remain authoritative. An unreachable endpoint produces no guessed
capability.

Claude advertises text, image and file input; it does not claim audio, video or
image generation. Codex advertises text and image input and exposes image
generation only when its image endpoint is enabled. Existing model rows need
an explicit verified reconciliation; the create route does not silently
overwrite them.

The Core public suite passed 137 tests and 23 subtests. The product's focused
metadata registration test passed. The older full product test driver cannot
collect in this modular checkout because `test_inplace_recovery` imports the
removed `openagent_server.models` package; this is a pre-existing suite defect.

## Publication and live verification

Core beta 10 was pushed to `openagent-core/main` and published at
https://github.com/openagent-uno/openagent-core/releases/tag/v1.1.0-beta.10
(`c35c535f`). Product beta 19 was pushed to `openagent/main` and published at
https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.19
(`2e680185`). The release bundles nine product wheels and the four Core wheels;
the product manifest SHA-256 is
`ea9e9e8ee1445f91d13fbb3e720f00acbc16077bb20b8b0eb5bcecc048b3b636`.

Friday on Bluehost and Mixout both run server `1.1.0b19`. Each passed
`openagent selfcheck`, `uv pip check`, and a live `/api/health` request after
restart, with zero service restarts. SQLite integrity checks passed on backups
made before upgrading; beta 18 environments remain available for rollback.

Both hosts also run `claude-sub-proxy` 0.1.3. The live `/v1/models` catalogs
advertise `text`, `image`, and `file` for all three Claude models. The installed
Core beta 10 discovers those exact fields on each host. An image chat request
through each live proxy returned `Red` for a red PNG (HTTP 200). On the beta 19
Friday installation, the Telegram desktop client then sent a text probe and
Friday replied `OK`. A separate solid-blue PNG was sent as a Telegram photo
with a one-word color question; Friday replied `Blu.` using
`local:claude-opus-4-8`. This verifies image reception, model vision and reply
through the actual Telegram channel after the upgrade. A one-second OGG Opus
audio attachment sent in the same chat appeared as a playable audio message;
Friday transcribed its spoken word as `Girasole.` using the same chat model.
Audio was handled by OpenAgent's transcription path, not by falsely advertising
native audio input on the Claude subscription proxy.

GlassPalace owns its own synchronization at Connect/Add models and is
documented in its repository.
