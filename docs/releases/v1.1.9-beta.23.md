# OpenAgent Server v1.1.9-beta.23

Session details can retrieve device history independently of connected computer
targets. Authorized users can open available computers from session and
automation run details. An agent owner can open the agent's configured desktop
directly from Devices.

Custom dashboards support isolated interactive HTML views with revisioned
assets and a permission-checked bridge for dashboard data and actions.
See [App beta 35](app-v1.1.0-beta.35.md) for the desktop viewer.

The [installed product receipt](../qualification/python-product-b23-2026-11-10.json)
records the qualified wheel cohort and installer checks.
