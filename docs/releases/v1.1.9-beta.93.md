# Server and CLI beta93

This release pins OpenAgent Core beta144. Opening an installed database avoids
reinstalling its journal triggers and rescanning historical automation rows.
A failed or cancelled Core database bootstrap closes its connection and rolls
back unfinished writes. Missing triggers still use the normal repair path.

The Core, Gateway, SDK and SQLite packages are pinned to one published cohort.

The stateless Chat Completions gateway also accepts native subscription
connections. Requests retain the same wire format and scoped authentication.
Core owns account selection and credential handling. Streaming preserves
sanitized upstream errors and never retries once a frame has been sent.
