# OpenAgent App 1.1.0 beta 56

- The goal bar above the composer and the session panel show how long the
  goal has been running. The bar has a pause/resume button.
- A cancelled or timed-out tool call on this computer no longer drops its
  capability connection, so the agent's running turn keeps the device (pairs
  with the Server change that reattaches a reconnecting device).

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
