# Product beta99

The standalone server adopts Core beta149's automatic catalog recovery for
text, image generation, transcription and speech. It retains account identities,
model rows, pins and settings while inheriting current authorization, budget,
capability and temporary-health checks from the shared runtime. Native
subscription backups preserve their borrowed account transports. Terminal provider
failures retain their safe cause without replay, including while a connection
is cooling down.

Fallback answers and executed tools remain in the same conversation after a
new turn or runtime rebuild. Older completed user-only fallback envelopes retain
their recorded answers as read-only historical context. Shared SQLite journal
writes also no longer leave pending results that can fail unrelated state saves.

Fresh standalone catalogs compose Core's default media generation capability
when its row is missing. Existing disabled, custom or operator-configured rows
remain unchanged. Core owns image selection and inference; the product only
composes the public capability.

App beta71 remains compatible with the server. App beta72 separately keeps a
failed turn's visible error when its canonical user history arrives; transcript
reconciliation does not silently replace that error with an empty answer.
No native App or embedding-host release is implied by these source changes. Public artifact qualification and an actual
host/channel pilot remain separate from source tests.
