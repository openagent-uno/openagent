# Server beta86 — shared subscription custody and public host CLI composition

This cohort consumes public Core beta136. Remote custody connections use exact
accounts without copying rotating tokens into each host. Subscription account
inventory reports the endpoint's actual sign-in capability and loads independent
connections with bounded concurrency. Local connection toggles and names do not
mutate another catalog's shared credential.

Installed domain adapters can compose the stock CLI through the public
`create_host_cli(engine_extensions_factory=...)` contract. Its per-invocation
factory supplies public Core EngineExtensions before stock server construction;
no host needs to replace the server class or copy its lifecycle. Top-level
commands/options are owned by each composed CLI, and invalid factories fail
before construction. Domain data and policy remain outside OpenAgent.

The App remains independently versioned. Deferred tool transcripts from beta85
are retained. Immutable wheel qualification, publication and actual host/provider
acceptance remain separate gates.
