# OpenAgent App 1.1.0 beta 41

Opening an existing conversation no longer looks like an empty new chat.
Over a remote connection the first transcript page can take several seconds;
until it arrives the transcript now shows placeholder turns instead of the
"At your service" screen, and if the load fails the chat says so and offers
Retry instead of silently staying empty. New conversations still open on the
usual start screen. The app keeps the existing application ID and local
profiles.
