# OpenAgent 1.1.0 beta63

Model-manager can add and modify providers and models while the runtime persists a conversation. Core beta32 acquires the SQLite writer in a short dedicated transaction instead of promoting a retained read snapshot. Failed writes roll back, and simultaneous first MCP calls wait for full database initialization.

The server, CLI and MCP bridge consume Core/SQLite beta32. Identities, existing sessions, credentials and model choices are preserved. Regression coverage includes the exact stale-snapshot failure, concurrent additions, rejected writes and catalog mutation. Native desktop bundles are unchanged.
