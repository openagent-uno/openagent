# App beta65 — account policy and accurate usage labels

Connections on supporting hosts update automatic fallback for all linked model
kinds of the named account. The description follows Core's declared text/image
policy; older hosts retain their text-only contract and update path. Provider
cards identify recorded text usage and distinguish unmetered image/audio usage.

Provider management is exercised against both older and newer account contracts,
including concurrent subscription accounts, API connections, typed model forms,
budget scopes and narrow layouts. Deferred transcript and tool-detail behavior
from beta64 is retained. Native publication and actual host/provider acceptance
are separate qualification gates.

Local qualification: TypeScript passed; 257 common tests passed; eight Electron
passes cover both account contracts, delayed enrichment/focus and deferred tool
detail authorization/reopening (two consecutive passes per scenario).
