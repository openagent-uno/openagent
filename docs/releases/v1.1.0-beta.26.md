# OpenAgent v1.1.0-beta.26: independent web-search compatibility

Product beta 26 restores live web search for agents migrated from the legacy
monolith. Those durable catalogs still contain a managed `web-search` row that
names the retired Core built-in, while the implementation now correctly lives
in the independent `openagent-tools` package. The mismatch left `tool-search`
healthy but omitted the three web tools from live discovery.

The standalone product now resolves only that exact legacy managed row to an
explicitly installed `openagent-web-search-mcp` executable. Fresh installs do
not auto-install or auto-register the optional package, and user-owned custom
rows are never replaced. The child process receives only ordinary browser and
runtime settings; provider keys and channel secrets are not forwarded.

The released web-search artifact remains
`openagent-web-search-mcp-1.0.0-beta.1.tgz` from Tools beta 4. Its official MCP
stdio boundary exposes all three expected tools, and a live browser-backed
summary query returns usable results. Product beta 26 remains paired with Core
beta 13 and Tools beta 4. The signed desktop App stays at beta 15 because this
repair changes only standalone server composition.
