# OpenAgent 1.1.1

A failed model call now tells the user what needs attention: a missing provider account,
a missing or unavailable model, expired or invalid authentication, exhausted credits,
a configured spending budget, temporary rate limiting or a context limit. These safe
messages survive durable runtime execution, live App/CLI streams, repeated requests
and the official channel bridges. Provider diagnostics and credentials stay out of
public error text. Clearing a conversation is no longer suggested for account failures.

The standalone server and CLI are stable 1.1.1, using published Core beta36 and
independent channel bridges beta15. Native App binaries retain their existing version;
the existing app displays these server messages without a binary update.

## Validation

- Core source and installed official wheels: 502 tests and 90 subtests each.
- Installed product regression suite: 417 tests and 101 subtests before the added
  real-Iroh provider-failure cases; authenticated model/tool execution, two-account
  isolation and replay are included.
- Shared App logic: 146 tests. Universal web export and Desktop TypeScript build pass.
- Real authenticated Iroh provider failures and idempotent replay: expired/invalid
  authentication and exhausted credits passed; private provider text is absent.
- Electron error rendering, navigation and child reasoning: two unchanged full passes.
- Provider error classification and channel delivery tests verify actionable allowlisted
  messages and reject embedded credentials or raw diagnostics.

Production rollout and public artifact evidence are recorded separately after their
respective checks. The previous stable 1.1.0 receipt retains its historical evidence.
