# Server 1.1.9b106

Operators can offer durable project tasks through configured project revisions and a private computer pool. Each admitted task binds a network member to a revision and a separate guest. The client can reopen the result and checkpoint after disconnecting. Operators may grant terminal, preview and suspend access separately.

The server and CLI adopt Core 1.1.0b166. Revoking project access also hides its session messages, turn history, search results and generated files. Once a host has recorded protected sessions, it must keep a reader that enforces their access checks. See the [configuration and rollback guidance](../site/guide/project-tasks.md).
