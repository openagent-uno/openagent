# OpenAgent v1.1.0-beta.10 release receipt

This product beta pins the independently published host-tools
[`v1.0.0b4`](https://github.com/openagent-uno/openagent/releases/tag/v1.0.0b4)
in the App and CLI consumer locks. The App capability registry remains scoped
to its verified client instance; the catalog does not expose a connected
desktop's tools to unrelated channels or deferred runs. Core beta 5 and Tools
beta 3 are unchanged.

The native host-tools release contains six platform archives, six detached
SHA-256 files, a matching Python wheel and an immutable `release-index.json`.
The matrix passed on
[run 36035151417](https://github.com/openagent-uno/openagent/actions/runs/36035151417).
Both macOS candidates were signed locally with the existing Developer ID,
accepted by Apple's notarization service, stapled and independently checked
with Gatekeeper. The App and CLI locks contain the same release index bytes
(SHA-256 `42f723ee3738e0f0188a7f9e152de09ef3bb7e75791c30bb59566078c2cb29a9`).

The nine Python product wheels were built from clean commit
`014d6bc76417fbbb0c4d8561f5deba74702c4896` with no overlapping import
payload. In a separate Python 3.12 environment, all nine installed alongside
Core beta 5 and Tools beta 3, dependency checking passed, and `openagent
selfcheck`, server, CLI and bridge entrypoints launched. The installed product
suite passed 75 tests and 21 subtests, including two-account/two-device Iroh
flows; focused CLI tests passed 30 tests. Iroh FFI event-loop cleanup warnings
persist after the passing integration tests.
The website installer's stable transitive-dependency constraints were also
rehearsed from the 38-wheel combined first-party wheelhouse in a fresh Python
environment; `pip check`, server self-check and CLI version all passed.
After publication, the public installer verified all 38 wheels against the
three release manifests and installed both server and CLI into an isolated
Python 3.13 environment; self-check, CLI version and `pip check` passed. A
transient GitHub HTTP 500 during an earlier download prompted bounded retries
for temporary network/server errors in the site installer.

The macOS Apple Silicon App was built from this source with the published
host-tools archive, signed, accepted by Apple notarization and packaged as a
DMG and ZIP. The packaged artifact smoke passed from both extracted installers,
checking embedded App version, update metadata, host-tools signatures,
packaged launch, and checksums. The App itself also passed strict `codesign`,
stapler and Gatekeeper checks. The DMG SHA-256 is
`c5b9fff4aed86bb666af8e5a39a781a8d81b28d81f580b304fd4a46942e4c7e4`;
the ZIP SHA-256 is
`6cfa6670afe84ee2b1aa90ad486903d6f40d027263d1b6f835e2508613f055f0`.
The packaged-App E2E passed against a temporary standalone server and an
isolated Electron profile: enrollment over Iroh, the uniform filesystem tool,
result persistence after reload, and the registered filesystem, editor, shell
and computer-control capability sources were verified. One intervening
attempt timed out while Playwright attached to a launched Electron process;
a clean retry passed. The intermittent attachment delay remains a test
reliability concern.

The complete cross-platform App/CLI installer matrix, the historical updater
transition, and provider-backed interactive sessions are distinct gates. This
beta is not a production cutover; the release manifest keeps the
`development-unqualified` label and records the exact published assets. All
19 assets at the
[`v1.1.0-beta.10`](https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.10)
prerelease matched local SHA-256 digests and byte counts after publication;
the product manifest SHA-256 is
`b5dbd30b26b7895ec230a3c4e52f5588ea8506e635d79bde8fc39574c741d89a`.
