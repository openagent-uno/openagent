# Python product 1.1.9 beta53

Core 95: files sent by a server-host agent reach the chat.

- Pins Core 1.1.0b95 (core, gateway, sdk, storage-sqlite).

- `send_file_to_user` on the server host uploaded the file and linked it to the
  session, then refused it with "The host publisher did not return a
  session-linked artifact": the check read through the shared database
  connection, whose open snapshot predated the upload. Core now reads the
  just-published attachment on a dedicated connection.
- Core also adds `restore_tombstoned_session` for conversations tombstoned by
  mistake whose history was retained (see Core's `docs/session-retention.md`).
- Host Tools stays 1.0.0b18; capability-host stays 1.0.0b4; product-config stays
  1.1.0b25.
