# OpenAgent v1.1.0-beta.14 attachment previews

The App uses one attachment component for user and agent messages. Image and video attachments open in an expanded viewer with adjacent Expand and Download controls. Audio attachments expose inline play/pause and seeking. PDF, text and code files open in a preview; code uses the App's existing Shiki renderer. Unsupported document types remain downloadable. The same component applies in App chat surfaces that use `MessageList`.

All nine Python product distributions advance together to beta 14 while retaining Core beta 7. The release changes the client attachment presentation; it does not add a GlassPalace-specific override to the OpenAgent runtime. The standalone server, CLI and model configuration retain the beta 13 ImageGen capability.

The web export and TypeScript check passed. All nine wheels were built from the exact clean release commit `640a1921f5d605d0294064f49cf25c4a5e000678`; the wheel manifest reports `dirty_snapshot=false` and unique payload ownership. The annotated tag and [canonical prerelease](https://github.com/openagent-uno/openagent/releases/tag/v1.1.0-beta.14) contain 17 assets: nine wheels, the manifest, and seven macOS arm64 desktop assets (DMG, ZIP, blockmaps, SHA-256 sidecars, and updater feed). The historical [App updater repository](https://github.com/openagent-uno/openagent-app/releases/tag/v1.1.0-beta.14) also contains the seven macOS assets under the same tag; it was archived again after publication.

The macOS app and DMG were Apple signed, notarized, stapled, and accepted by Gatekeeper. Installer smoke checks passed against both the ZIP and DMG. `/Applications/OpenAgent.app` was upgraded to beta 14, launched, and connected to Friday on Bluehost. The image previously generated by Friday with the temporary Spicy Sparks Codex subscription proxy remained available in the chat. The installed App expanded it and saved `img-1790976684-f685be53.png`; the 1,650,759-byte download has SHA-256 `e62ade516a9b13f1da4c37796272321d4559a277354ce7aa03039066d74dc68c`, matching the Friday artifact.

Friday was upgraded from beta 13 to the exact beta 14 wheels in `/srv/friday/releases/v1.1.0-beta.14/venv`, after a verified online backup at `/srv/friday/backups/pre-beta14-20261002-2145`. `pip check` and `openagent selfcheck` passed; the systemd service remained active with zero restarts, and both loopback API health probes returned version `1.1.0b14`. The temporary Codex provider, model, key file, and tunnel used for the ImageGen exercise were removed, and the session was returned to `/model auto`. The Claude subscription proxy returned HTTP 429 during the first test prompt, so the successful live generation used the authorized Codex subscription proxy. Windows and Linux native App installers were not produced for this release. Audio, PDF, and code preview rendering passed the build and component checks but was not exercised with real files in Friday's installed App.
