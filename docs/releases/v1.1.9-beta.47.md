# Python product 1.1.9 beta47

Moves the server and the CLI to Core beta89. MCP sources can now reference host
secrets instead of storing credentials: a header value (remote sources) or
environment value (stdio sources) may contain
`${secret:OPENAGENT_MCP_SECRET_<NAME>}`, resolved from the server process
environment when the source connects. Only the reserved prefix can be
referenced; an unresolvable reference keeps the source unavailable with failure
code `secret_unavailable`. The value never reaches the catalog, status, logs or
model context. The `mcp-manager` tools accept `headers` and show header values
masked unless they are reference-only. See Core `docs/mcp-secret-references.md`.

Core beta87 and beta88 come along: parallel mutating calls of one principal are
serialized instead of refused, and hosts may register the opt-in channel message
capability. Host Tools stays at beta18 and `openagent-capability-host` at 1.0.0b4.
