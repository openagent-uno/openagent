# Python product 1.1.9 beta49

Core 91, schedule previews in the task's own timezone, and neutral examples.

- Pins Core 1.1.0b91 (core, gateway, sdk, storage-sqlite): background models
  (compaction summariser fallback, quality-monitor judge) are chosen by
  properties — operator choice, then self-hosted, then cheapest of another
  provider — never by a vendor name.
- `/api/cron/describe` accepts `timezone` and evaluates the expression in it,
  returning each run with its offset and the timezone it used (UTC when none is
  given, as the scheduler does); an unknown timezone is a 400. The app's "Next 3
  runs" preview of a task now matches the task's real next run.
- `openagent-product-config` 1.1.0b25: the network prompt's invitation example
  uses a neutral handle.
- Tests, fixtures, CLI help and examples use neutral names; server copies of
  the compaction and quality-monitor tests follow Core 91.
- Host Tools stays 1.0.0b18; capability-host stays 1.0.0b4.
