# Server 1.1.9 beta77

Pins Core 1.1.0b120.

- A goal interrupted by a restart starts again. When the agent's owner sets,
  edits or resumes a goal (app, REST or `/goal`), the server keeps a durable
  delegation for that conversation and that exact objective, valid only
  while the goal is active. About twenty seconds after a start
  (`OPENAGENT_GOAL_RECOVERY_DELAY_S`), every active goal whose last turn the
  restart interrupted resumes once under that delegation, and the agent is
  told to check the state before repeating anything.
- A goal without a delegation (set by another member, or changed outside the
  app, the API and `/goal`) pauses and shows why. A goal interrupted twice in
  a row pauses instead of looping.
- Goals set before this release have no delegation until their owner saves
  or resumes them once.
