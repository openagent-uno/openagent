# OpenAgent v1.1.0-beta.27: unified workflow capability dispatch

Product beta 27 pairs the standalone server with Core beta 14 so workflow
`mcp-tool` blocks validate and execute through the same authorized Runtime
capability catalog used by interactive turns and the gateway.

The mismatch was exposed by an end-to-end web-search canary after beta 26:
the API listed all three live `web-search` tools, but the workflow executor
consulted the deferred Agent pool, where standalone intentionally keeps only
`tool-search`, and failed with `MCP 'web-search' is not loaded`. The executor
now discovers the exact source and tool in the Runtime catalog and invokes its
opaque reference under the current execution context. If the capability is
absent there, execution is rejected instead of falling back to a legacy pool.

Core's source and clean-wheel suites pass 147 tests plus 23 subtests. The
standalone product suite passes 82 tests plus 21 subtests. Product beta 27 is
paired with Core beta 14 and Tools beta 4. The signed desktop App remains beta
15 because this repair changes only server-side workflow execution.
