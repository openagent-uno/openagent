# Channel bridges beta15

Official conversational bridges deliver the same actionable AI account, model,
authentication and quota errors as the standalone App and CLI. Failed native runs
return safe public text after current audience authorization. Legacy delivery accepts
only the Core allowlisted messages; arbitrary diagnostics receive a generic error.
The old suggestion to use `/clear` for every provider failure is removed.

Requires published OpenAgent Core beta36 or newer. Regression cases cover safe
messages, secret rejection, native failure delivery and audience revocation.
