# OpenAgent App 1.1.0 beta 55

- A conversation with a goal shows it on one line above the composer, in a
  tab attached to it: state, the start of the objective and continuations.
  Click it to open the goal dialog, where you can read, edit or remove it.
- The goal dialog can remove the goal; the side panel and the composer bar
  update together.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
