# OpenAgent App v1.1.0-beta.38

Chat follows new messages and tool cards at the bottom. Scrolling up pauses
following. Sending a message returns the view to the bottom. Completed turns
expose their private text fork even while the next shared turn is streaming.

The active agent name appears in the sidebar and on its replies. Delegation
cards fill the transcript width. Server beta 25 links the exact child session
while a delegated tool is running.
