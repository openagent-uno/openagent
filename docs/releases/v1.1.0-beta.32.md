# OpenAgent v1.1.0-beta.32: long-running automation deadlines

Product beta 32 fixes an outer Runtime deadline that could cancel an approved
scheduled task or event before its own execution-policy timeout elapsed. This
was reproduced on Mixout's marketing pipeline: provider fallback succeeded and
the agent completed 39 tool calls, but the Product wrapper cancelled the run at
960 seconds while its generated social assets were still being prepared.

The Runtime request now remains alive for an explicit task or event
`execution_policy.timeout_seconds`, plus a bounded 30-second finalization
window. Definitions without an explicit timeout retain the existing 960-second
default. The inner scheduler/event budget remains authoritative, so extending
the outer deadline does not make an automation unbounded.

Regression coverage verifies the submitted Runtime deadline for a long-running
task, applies the same rule to events, and preserves the workflow default.
Product beta 32 is paired with Core beta 17 and Tools beta 4. The signed desktop
App remains beta 15 because this repair changes only the server runtime.
