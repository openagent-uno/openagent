# App beta 76

Long conversations keep the history you have already opened when the app
reconnects. Opening a result in the middle of a long turn retrieves the
surrounding messages. With a compatible server, the transcript shows the
assistant’s text next to the tool it described. Copy uses the complete answer.

An unsent message stays at the time it was sent, where its delivery notice
can be dismissed. An attachment stays in the composer until it is ready.
A failed upload can be retried or removed from the draft. Switching chats,
starting a session or changing accounts keeps each conversation's text and
attachments together, including uploads that finish while you are away.
For supported read operations, macOS can use the permission granted to the
app when the separate tool process receives an operating-system denial.
If access still requires a selection, the request identifies the item and
reports acceptance, refusal or expiry to the agent. A cancelled or expired
file picker closes so the next request can open its own picker.

The release workflow exercises opening, paging and reconnecting in a long
conversation twice. File access, cancellation and reconnect tests use
synthetic data.
