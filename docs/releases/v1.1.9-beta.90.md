# Product beta90 — embedded subscription stream recovery

The standalone server and client packages adopt Core beta141. Codex stream
chunks and cleanup keep one worker owner for the account's cross-process
admission locks. Completed and cancelled turns therefore release their slots;
subsequent turns do not wait for the full queue timeout because a previous
stream changed pool threads. Cancellation also interrupts admission, pacing
and retry waits and closes established upstream reads.

Core's offline localization operation converts reviewed remote subscription
connections in place. Operators can retire separate custody listeners after
qualifying every consumer against one private shared rotating store and
admission lane, while keeping account/model IDs, enabled flags, model settings,
budgets, fallback groups, defaults and session references. This is an explicit
stopped-writer operation, never automatic token discovery or duplication.

Source qualification, publication and installed-host acceptance remain
separate. Existing App clients use the same protocol and profiles.
