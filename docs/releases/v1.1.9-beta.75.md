# Server 1.1.9 beta75

Pins Core 1.1.0b118. Includes beta73 and beta74, which were never deployed
on their own.

- Models: a provider's endpoint, key or account change (for example after a
  sign-in) re-reads which inputs its language models accept; `POST
  /api/providers/{id}/refresh-capabilities` does it on demand, and
  `GET /api/models/available` reports the inputs each model would be
  registered with. Inputs set by hand are never overwritten.
- Accounts: `GET /api/accounts` gives every account and provider a `status`
  (`ok`, `rate_limited`, `auth_expired`, `unreachable`), so an expired sign-in
  is no longer reported as a usage limit.
- App (beta 59): Settings → Models is one grid of every configured model
  (access, type, inputs, status, subscription quota, pricing, role) with the
  budgets, and "Add model" is a three-step wizard.
