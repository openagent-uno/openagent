# Server 1.1.9 beta71

Pins Core 1.1.0b110 (unchanged).

- The goal API changes a goal while a shared transport owns the
  conversation. PATCH, PUT and DELETE on `/api/sessions/{id}/goal` answered
  409 whenever a shared conversation had its transport attached, so the
  app's goal panel and dialog could not pause, resume or edit a goal while
  the agent worked. Admin access is still required.
