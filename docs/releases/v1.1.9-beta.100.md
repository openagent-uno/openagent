# Product beta100

The server, CLI and shared transports adopt the public Core beta150 cohort.
Streaming terminal metadata now identifies the model that actually answered
after account rotation or a backup-model recovery. Channel footers, including
Telegram, inherit that value through the existing shared collector instead of
displaying the original or an older delegation.

The correction belongs to Core. This product release adds no local routing or
channel workaround and retains stored accounts, models, settings and budgets.
The independently versioned configuration package remains beta28, Host Tools
and Device Tools remain beta18, and App beta72 remains compatible without a
new native App build.

Installed-cohort tests, public package publication and live channel acceptance
are separate qualification steps.

The public site installer selects the qualified beta100 product manifest and
the beta150 coupled Core manifest by exact digest. Independent module, channel,
configuration and tool selections remain at their existing qualified pins.
