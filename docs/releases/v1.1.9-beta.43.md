# Python product 1.1.9 beta43

Adopts Core beta86. A provider stream that fails with a transient error before
producing output is retried once on the same model, so one network
interruption no longer ends a long agent turn. The vault no longer stops
versioning behind an abandoned `.git/index.lock`: such a lock is removed and
every Git failure is logged, and validating a note recognises links to notes
written a moment earlier. Also includes the unreleased main changes since
beta42. Identity, vault, automation and Custom View data remain in place.
