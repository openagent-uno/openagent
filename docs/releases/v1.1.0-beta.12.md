## Standalone server rollout

The Performa, Ribel and Yoanna installations were upgraded from beta.8 to
beta.12 on the `performa` host. Before the rollout, a read-only check found no
active task, workflow, session or UI action runs. Each SQLite database was
backed up online with its `openagent.yaml` and memory vault under
`/home/ubuntu/.local/share/openagent/deploy-backups/2026-10-02-beta12/`;
`PRAGMA integrity_check` returned `ok` for all three databases.

The official installer created an isolated beta.12 environment at
`/home/ubuntu/.local/share/openagent/releases/v1.1.0-beta.12/venv`.
`pip check` and `openagent selfcheck` passed there, then the shared stable
launcher was switched atomically. The three systemd services were restarted
one by one. Final checks found each service active with zero restarts and
`/api/health` reporting `status: ok`, version `1.1.0b12` on localhost ports
38657, 42915 and 44763 respectively. Real Telegram or Slack delivery and a
paid provider image generation turn were not exercised during this rollout.
