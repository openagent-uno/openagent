# Server 1.1.9b104

Private WhatsApp replies on the standalone server now recognize incoming
GREEN API notifications that identify the configured instance and give the
same personal address for the sender and the chat. The bridge preserves the
existing audience checks for groups and ambiguous notifications.

The server and CLI include Core 1.1.0b157. Operators using the migration
commands can recover linked private session history, keep protected notes
protected across a rollback, and attest supported legacy engine history.
The server installs channel bridges 0.1.0b28.
