# OpenAgent App 1.1.0 beta 58

- The composer's microphone dictates (desktop and web): the recording is
  transcribed and the text appears in the composer, where you can edit it
  before sending. No audio file is attached and nothing is sent on its own.
  Replies to dictated messages are text and are not read aloud; live voice
  mode still speaks. Needs Server 1.1.9 beta74.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
