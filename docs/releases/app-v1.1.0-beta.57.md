# OpenAgent App 1.1.0 beta 57

- Loops panel (desktop): "Use this computer" lets an approved loop use this
  computer while it is connected; "Stop using this computer" withdraws it at
  once. Only the person who approved the loop sees the control, and only on
  their own device. Needs Server 1.1.9 beta73.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
