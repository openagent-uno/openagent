# OpenAgent v1.1.0-beta.23: standalone automation authorization repair

Scheduled tasks, workflows, and events created before the standalone durable
authorization gate had no matching row in `standalone_automation_grants`.
Their definitions remained enabled and due, but the scheduler skipped them.
The same gap affected built-in tasks seeded outside the authenticated
management path. On the five reachable production agents, 46 enabled tasks
had zero exact-revision grants, which explains why unrelated agents stopped
running scheduled work at different dates without a database-integrity error.

This release keeps the security boundary: startup does not auto-adopt old
definitions. An authenticated owner can review the current definition and its
SHA-256 digest, then approve only that exact revision. Core beta 12 exposes the
same review and approval operations as agent tools. The App beta 15 shows a
review-required banner and digest in task, workflow, and event editors; Run and
Test stay disabled until approval.

Approval reconciles overdue recurring schedule cursors to the next future
occurrence instead of replaying every missed slot. It does not remove durable
workflow requests or event deliveries. A one-shot task remains eligible while
its scheduler-owned occurrence is running, executes once, and has its grant
revoked when the occurrence completes. Editing or disabling a definition also
invalidates its previous grant.

Qualification before publication covered 81 Product tests and 21 subtests,
143 Core tests and 23 subtests, the TypeScript checks, the desktop test build,
and the universal web export. Focused tests exercise historical tasks,
workflows, events, built-ins, stale-digest rejection, unauthorized scheduler
skips, and an approved one-shot task end to end. Release-wheel and live-agent
receipts are recorded after publication and rollout.
