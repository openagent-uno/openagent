# Beta60: complete bounded channel history

The standalone server consumes the separately published channel bridges beta12
with Core beta28. A host can negotiate attributed history bytes from the old
64 KiB default up to 256 KiB. The bridge checks complete records again after
historical speech transcription. A byte/256-part overflow reports unavailable
history through fresh authorization and starts no partial task. Other history,
file, media, actor and audience limits remain unchanged.

Only the pure Python server framework is newly built for this product family;
eight immutable public component wheels retain their original provenance after
exact source equality checks. Installed/public product qualification is recorded
separately. These deterministic fixtures do not establish live provider, native
application, frozen server or automatic-update acceptance.
