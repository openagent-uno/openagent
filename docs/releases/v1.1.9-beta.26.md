# OpenAgent Server 1.1.9 beta 26

- The gateway publishes the child session link while a delegated run is active.
  Links are tied to the exact parent tool call and honor the child session's
  access policy.
- This release adopts Core beta 73. The team-provider adapter preserves the
  provider's tool call ID while resolving lazy delegation tools.
- The update keeps the existing runtime identity and SQLite data in place.
- Installed-device qualification checks each account's committed tool
  invocation records through a fresh read-only SQLite connection.
