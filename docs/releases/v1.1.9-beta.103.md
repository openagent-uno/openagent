# Server 1.1.9b103

A new agent directory stores its memory and revision history in the standalone
SQLite database. Existing agents can switch their Markdown/Git vault through
an explicit import with a verified corpus receipt. The authenticated vault
API supports revision inspection, restore, search and links.

Scheduled dreams use the original task grant and calendar. The document
worker restricts maintenance to the selected vault. Where the owner also
granted session access, the review can inspect authorized activity and
suggest follow-up work. The server checks the original sources again when
a reader opens the result.

Reading a saved note binds the run, its derived output and its attachments to
that revision. Searches, saved app views, WebSockets and downloads recheck
access before delivery. A copy of a previous installation can also attest
private historical turns from its sealed source before making them available
to the model. The migration receipt records the original identifiers and scope.
