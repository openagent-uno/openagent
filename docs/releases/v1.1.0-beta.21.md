# OpenAgent v1.1.0-beta.21: compatible server and CLI packages

Beta 20 introduced opt-in server-owned browser and desktop capabilities. The
first full-install smoke test found that its unchanged CLI wheel still pinned
`openagent-host-tools==1.0.0b4`, while the server now requires `b5`. Beta 21
updates the CLI dependency and advances the server and CLI package versions so
they can be installed together with `openagent-device-tools==1.0.0b4`.

The server-owned capability design and Friday's staged Telegram browser and
desktop test are documented in [beta 20](v1.1.0-beta.20.md). The installation
must pass `uv pip check` before a production switch. The release includes Python
wheels; signed desktop bundles are a separate qualification and release.
