# Python product 1.1.9 beta37

Adds `GET /api/sessions/{id}/turns`, a compact paged index of the human
prompts in a session (stable message id, ordinal, author, a caller-relative
`own` flag and a bounded preview). App beta 40 uses it for the transcript turn
rail. Core beta83 and the beta35 reset fixes are unchanged. Existing identity,
vault and automation configuration remain in place.
