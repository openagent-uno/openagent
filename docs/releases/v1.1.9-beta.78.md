# Server 1.1.9 beta78

Pins Core 1.1.0b122 and channel bridges 0.1.0b27.

- Channels answer a voice note with text. The server was still pinned to
  channel bridges 0.1.0b24, which sent a synthesized audio copy of the reply
  to a voice note on Telegram, Discord, Slack and WhatsApp; beta74 fixed the
  bridge source but not the pinned package. Bridges 0.1.0b27 carries the fix
  (and the host-delivery additions of b25 and b26).
- A goal objective longer than 4000 characters is refused with its length
  instead of being cut silently (Core beta121).
- A turn rebuilt from the run journal keeps the model that answered (Core
  beta122).
