# OpenAgent Python product 1.1.9 beta 94

The standalone server accepts stateless chat completions at
`POST /v1/chat/completions` as well as `POST /api/llm/chat/completions`.
Both routes use the same handler and Core beta 144 configuration for provider
selection, subscription accounts, tool calls, and streaming.

The inference token permits the exact chat-completions POST under `/v1`.
The existing permission boundary for administration, vault and sessions
remains enforced. See the [usage guide](../USAGE.md#stateless-chat-completions).
