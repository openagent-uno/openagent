# OpenAgent 1.1.0 beta69

The standalone product adopts official Core/SQLite beta34 and channel bridges
beta14. Same-name Slack uploads retain independent private files and their
original display names. Interactive runs have no hidden sixty-tool cutoff;
explicit operator and execution-policy limits, lean background limits,
cancellation, authorization and host deadlines continue to apply.

The shared fixes are in the independently published components, without a
product-local overlay. Source and installed-component regressions cover a PDF
plus seven identically named images, a real native runner that prepares a
document beyond sixty calls and delivers it, and explicit budget enforcement.
The combined installed component suite passed 377 tests and 98 subtests.

Product package and normal installer acceptance are recorded separately after
building this product version. No new native App installer or live channel
acceptance is implied by the component fixtures.
