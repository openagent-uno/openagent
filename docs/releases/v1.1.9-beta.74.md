# Server 1.1.9 beta74

Pins Core 1.1.0b117 (b115, b116 and b117) and includes everything in
beta73, which was never deployed on its own.

- Voice notes are input. In the app, the composer's microphone dictates: the
  recording is transcribed and the text appears in the composer to review
  and send. No audio file is attached. Telegram, Discord, Slack and WhatsApp
  answer a voice note with text and no longer send a synthesized audio copy
  of the reply (Core b116 drops the same rule in the stream session). A reply
  is spoken only in a session with speech on, such as live voice mode.
- Images reach Claude models behind a proxy (Core b117): a model whose
  provider declares a `vision` capability receives the user's images
  natively, even when its stored declaration was text-only.
- A backup model that never answers no longer holds the turn (Core b115): it
  has 120 seconds to send its first output before the next backup is tried.
- From beta73: a connected device can be lent to one of its owner's
  automations ("Use this computer" in the desktop app's Loops panel).
