# OpenAgent App 1.1.0 beta 54

- The session panel previews a conversation's goal in its first five lines.
  Open it (or click the preview) to read the whole objective in a dialog,
  edit it in place (an active or paused goal keeps its status and budget) or
  set a new one. Setting a first goal uses the same dialog.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
