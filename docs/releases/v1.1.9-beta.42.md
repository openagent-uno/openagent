# Python product 1.1.9 beta42

Supersedes the unpublished beta40 and beta41 tags. Their qualification could
not install the product's Host Tools: beta40 still declared Host Tools beta15
next to OpenAgent Shell 1.0.0b4, and beta41 declared beta16 while the server
resolved Host Tools from the in-repository path, which the public qualification
cohort cannot install. The server and CLI now consume Host Tools beta16 as the
published, hash-pinned wheel, like Core.

Contents: Core beta84 keeps failed or cancelled turns' executed tools in the
model's history, closed by a note that the turn ended without a final answer;
server-host shells refuse a sub-second `timeout` with an error naming the unit
(milliseconds); on macOS a GUI-launched host's shell resolves the user's
login-shell `PATH`. Identity, vault, automation and Custom View data remain in
place.
