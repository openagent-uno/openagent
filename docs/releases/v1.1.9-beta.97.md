# Server beta97 and App beta71

Verified network members can open Models & Providers without an administration
error. The response contains only connection names and enabled status, and the
App renders the same read-only overview used by other management pages.
Credentials, account details, connection definitions and edits remain owner-only.
The existing owner-only page visibility setting also applies to this overview.

Model selection and chat execution keep their existing authorization. Provider
rate limits remain independent of page permissions. Core beta146 retains the
Claude disabled stream-timeout correction introduced with Server beta96.

The regression exercises the actual identity middleware and SQLite catalog,
including suspended users, revoked devices, mutation denial and owner access.
