# Server and CLI 1.1.0-beta.47

This public prerelease adopts shared connectors SDK 0.1.9. Outlook Calendar list/get includes the optional provider-reported `canShare` boolean, preserving missing/false values and rejecting malformed data. It supplies ownership metadata for an explicitly authorized host action; write grants, scopes and connection ownership are unchanged. Old Calendar page tokens must restart at the first page after this fixed-projection update.

SDK 0.1.9 also distributes the corrected broker startup validation for Google Calendar and Microsoft configurations. The catalog remains 114 official connectors plus Custom MCP and 397 operations; Slack joins the seven common provider defaults after its verified distribution and broker activation. Explicit empty configuration/environment opt-outs remain effective; Google Testing and SharePoint remain explicit operator choices. No new provider grant, Calendar write or SharePoint account/site access is qualified by this release.

Only server/CLI wheels are rebuilt. Seven unchanged product component wheels retain their immutable source/byte proof, Core and SQLite remain beta22, Host Tools beta6. No native App rebuild or new GUI qualification is included. The public release has 12 checksum-verified assets from source `1140364d0e662237336df79166db9d8d10e54781`. Qualification passed 215 installed tests, 15 React source scenarios, acquisition/readiness/catalog and source-provenance guards. Normal public installer qualification is recorded separately; the release qualification does not start a server or grant provider access.
