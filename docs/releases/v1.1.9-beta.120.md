# Server beta 120

Server beta 120 uses Core `1.1.0b184` and Channel Bridges `0.1.0b35`.

When the file vault is required, the gateway waits for it to finish startup.
If its first handshake times out, the module waits for the retry series already
scheduled by Core. It publishes its service after all required sources complete
discovery. A complete catalog can contain zero tools. Startup fails on a permanent
error or when retries are exhausted. Recovery makes no tool calls. Each later
tool call checks the caller's current permissions.
[Standalone module startup](../modules-v1.1.md) and [Core retry timing](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.184/docs/mcp-transport-recovery.md#bounded-reconnect-for-configured-sources).

An OpenAI-compatible subscription can return HTTP 200 and report a 401 in the
event stream. Before the first provider output frame, a configured account
group can try another eligible account for the same model. Budget and access
checks still apply. After any output frame, even one without text, an error
ends the stream and keeps the partial response without replaying the request.
Synchronous and asynchronous streams follow the same rule.
[Subscription accounts and API connections](../site/guide/models.md#subscription-accounts-and-api-connections) and [Core account routing](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.184/docs/provider-accounts-and-backups.md).
