# Server beta 120

Server beta 120 includes Core beta 184. If a required local MCP source such as
the file vault takes longer than the first handshake, its module waits for the
scheduled retries. The module publishes its service after all required sources
complete discovery. A successful discovery can return zero tools. A permanent
error or exhausted retries fails startup. Each subsequent tool call checks the
caller's current permissions.
[MCP startup and recovery](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.184/docs/mcp-transport-recovery.md#bounded-reconnect-for-configured-sources).

An OpenAI-compatible subscription can return HTTP 200 and report a 401 in the
event stream. Before the first provider output frame, a configured account
group can try another eligible account for the same model. Budget and access
checks still apply. After any output frame, an error ends the stream and keeps
the partial response without replaying the request. Synchronous and
asynchronous streams follow the same rule.
[Subscription account routing](https://github.com/openagent-uno/openagent-core/blob/v1.1.0-beta.184/docs/provider-accounts-and-backups.md).
