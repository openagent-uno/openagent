# Server beta 82 — stateless native connection testing

The connection test passes its authorized host database to Core beta 130.
Native subscription probes resolve the exact account and its settings, without
replaying or writing session history. Owned probe resources close on failure
and cancellation as well as success. App beta 61 remains compatible.

Includes [Server beta 81](v1.1.9-beta.81.md). This follow-up supersedes beta 81
for the provider migration pilot.
