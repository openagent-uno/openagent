# OpenAgent Server v1.1.9-beta.19

Shared chat snapshots record where each tool call first appeared in the
visible reply. App beta 32 uses these positions to show tool cards between
the preceding and following text. Completion and error events update the
card at its original position. The gateway keeps the full reply and its
rich content in the existing snapshot fields for older Apps.

The positions apply to live and recently observed turns. When history
replaces a live turn, the App reuses its positions if the saved reply matches
the observed text. History without positions follows its saved order.

rows and confirmed the rendered order. The installer verified the complete
