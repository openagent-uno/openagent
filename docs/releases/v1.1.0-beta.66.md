# OpenAgent 1.1.0 beta66

Standalone channels release canonical delivery files immediately after sending, on failure as well as success. Both the shared provider and gateway ownership registries are cleared, preventing a long-lived bridge from eventually exhausting its media-file limit. Cleanup verifies the registered inode and preserves replaced files and symlinks. Existing legacy scratch-file cleanup remains separate.

This completes beta65's generated-asset delivery fix for Telegram live and final-only replies. Regression tests cover normal cleanup and file/symlink replacement through the real standalone provider adapter. Core/SQLite beta32, channel bridges beta13, the Telegram session identity fix and native desktop bundles remain unchanged.
