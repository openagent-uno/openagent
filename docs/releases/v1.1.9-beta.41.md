# Python product 1.1.9 beta41

Supersedes the unpublished beta40 tag, whose qualification failed because the
product still declared Host Tools beta15 (OpenAgent Shell 1.0.0b3) while
pinning OpenAgent Tools beta7. This release declares Host Tools beta16.

Contents are those described for beta40: Core beta84 keeps failed or cancelled
turns' executed tools in the model's history, closed by a note that the turn
ended without a final answer; server-host shells refuse a sub-second `timeout`
with an error naming the unit (milliseconds); on macOS a GUI-launched host's
shell resolves the user's login-shell `PATH`. Identity, vault, automation and
Custom View data remain in place.
