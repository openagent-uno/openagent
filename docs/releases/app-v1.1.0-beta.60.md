# OpenAgent App 1.1.0 beta 60

- Sign in to a subscription from the app. Under a subscription provider's
  accounts (Add model wizard, a model's provider section, providers with no
  models) there is **Add account**, and **Sign in again** when an account's
  sign-in expired. The app opens the provider's sign-in page; you paste the
  code it shows, or the address of the page you land on, and the account is
  added. Needs Server 1.1.9 beta79 and a subscription service that supports
  sign-in from a client.

The app keeps Host Tools beta18, the existing application ID, local profiles
and device consent.
