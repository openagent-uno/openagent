# Server 1.1.9 beta68

Pins Core 1.1.0b110 (unchanged from beta67).

- A connected device stays in a running turn across a capability reconnect.
  A cancelled or timed-out mutating call no longer makes the desktop drop
  its capability connection, and when the same device instance reconnects
  within five minutes, a turn that was using it gets it back without a new
  grant. A new generation, a revoked device or the grace running out still
  revoke it.
