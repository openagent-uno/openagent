# OpenAgent Server v1.1.9-beta.22

Authenticated network members can browse operational pages by default. Agent
owners can limit visibility and transfer ownership from the app or CLI.
Scheduled run details link to transcripts according to the viewer's session
access and report known timeouts with the configured execution limit. Run
history and saved output remain available according to the run's permissions.

Use scheduled tasks and custom dashboards for agent-specific quality and cost
reports. The upgrade disables retired built-in reporting tasks and preserves
their run history. Product Config beta 24 ships with this release.

The [installed product receipt](../qualification/python-product-b22-2026-11-10.json)
records the exact wheel cohort and installer checks.
